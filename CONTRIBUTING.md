# Contributing

Thanks for helping improve this open hardware prototype. Useful contributions include fit measurements, printer/material settings, clear photos of test prints, reproducible bug reports, source changes, and documented test results.

## Please include

- The design revision or source commit you tested.
- Printer, material, slicer and relevant settings.
- Which part/interface was tested and what happened.
- Measurements in millimetres wherever possible.
- Photos that show the issue clearly, if available.
- A concise explanation of any proposed source change.

## Changes to source

- Preserve existing licence and attribution notices.
- Give modified files a revision/date and a short change note.
- Keep changes parametric where practical; avoid unexplained independent scaling of STLs.
- Do not describe the design as load-rated, certified or safe for overhead use without credible independent validation and supporting evidence.
- Do not report a fit check as a structural or safety test.

By submitting files or changes to a public repository, make sure you have the right to share them under the project licence. A contributor should clearly state any third-party content or different licence that applies.
